## How to read these numbers (limitations)

- The seeded set was written by the team alongside the engine, so these numbers show regression safety and coverage, **not independent accuracy**. Expect lower results on real content.
- Precision counts any finding outside `expect` and `also_ok` as a false positive. `also_ok` lists co-triggered findings that are legitimately correct for the text.
- Tone and messaging use a lexicon heuristic when no LLM key is set. It only recognises listed phrases, so subtle tone problems are missed by design.
- Red-team variants are partly hand-written and partly mechanical. The tightened rules were derived from the same variants they are re-tested on, so the 'after' column shows the loop works, not that the rule is now complete. Run it again with a new variant set to find new loopholes.
- Hidden-text detection covers white, same-colour-as-background, tiny, off-page, invisible and transparent text, HTML comments and zero-width characters. Text hidden behind images, in annotations or in images is not covered.
- Image text is not read without an LLM vision key, so wording inside images is listed as not checked.
